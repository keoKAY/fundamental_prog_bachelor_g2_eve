# OOP 
Object-Oriented Programming: 
2: Class - Object 
**4 Principles**: 
    - Encapsulation:  
        - binding , wrapping data to single unit 
        (data member, function member )
        - data hiding
        - read write = setter and getter
    - Inheritance: 
        - sub inherit from base 
        - Parent = Super = Base 
        - Child = Sub = Derived 
    - Polymorphism: 
        -  many form 
            - overload (Compile-time Polymorphism)
            - overriding (Runtime Polymorphism)
    - Abstraction: 
        - abstract class: 
            - at least has 1 pure virtual function 
        - interface (all pure virtual function )
        - hide complexity of implement
